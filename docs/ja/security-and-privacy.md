# セキュリティとプライバシー

日本語 | [English](../en/security-and-privacy.md)

## ローカル処理と更新確認

組み込み変換はローカルで動作します。文書をアップロードせず、文書内の外部URLを取得せず、表計算の数式を実行せず、任意のプラグインを自動探索しません。

GUIは公開GitHub Releases APIへ短いHTTPSリクエストを送る場合があります。文書内容、ファイル名、ローカルパスは送らず、更新を自動インストールしません。起動前に`DOCREDOCK_DISABLE_UPDATE_CHECK=1`を設定すると通信を無効化できます。

## 非表示情報と共有

閲覧用出力の既定値`visible`は、認識できるOfficeの非表示テキスト、非表示／veryHiddenシート、非表示行・列、非表示スライド・オブジェクト、ノート、コメント、変更履歴をMarkdown投影から除外します。`sanitized`はさらにメタデータ、派生・OCR情報、ヘッダー等を除外します。外部の`.assets/`には、選択ポリシーで含まれるノードから参照される画像だけを出力します。

`complete`は意図的に非表示情報とメタデータを含め、`HiddenContentIncluded`警告を出します。出力を機密情報として扱い、共有前に確認してください。可視性情報の表現はOffice文書の作成ソフトによって異なるため、どのポリシーも人による確認の代わりにはなりません。

`.md`と`.assets/`の両方に加え、埋め込みdata URI、保存済み計算結果、OCR出力も確認してください。実験用の`.drmd`と`.drmdpkg`は元文書バイナリや復元情報を含む場合があり、元文書と同じ機密区分で扱う必要があります。

## 信頼できない入力

DocRedockはXML DTD、アーカイブtraversal／過大展開、symlink escape、不審な数式、対応外の保護構造を検査します。主な上限は元文書200 MiB、Markdown 16 MiB、検証済み埋め込み画像1件10 MiB／合計50 MiBです。

信頼できない文書は隔離した利用者権限で処理し、組織のマルウェア対策を適用してください。

## 脆弱性を報告する

機密報告や実文書を公開Issueへ投稿しないでください。[SECURITY.md](../../SECURITY.md)に従い、機密情報のない最小の合成再現例を使用してください。
