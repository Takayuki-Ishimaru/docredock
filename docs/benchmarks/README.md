# Benchmarks

Benchmark documents contain methodology, measured values, limitations, and interpretation. Entry-point READMEs intentionally keep only a short summary.

## Available study

- [AI document-format token efficiency, 2026-08-25](../AI_DOCUMENT_FORMAT_TOKEN_BENCHMARK_2026-08-25.md)

In one local experiment using a synthetic XLSX, Markdown input used 74.1% fewer input tokens than direct Excel access. This is a measured example, not a universal performance guarantee; results vary with the document, toolchain, model, and question.
