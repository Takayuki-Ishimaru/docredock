# DRMDサイドカーと画像表示 — v0.1.2履歴

> **Status: Historical**
> **Implemented in: v0.1.2**
> **この文書は現在の利用ガイドや形式仕様ではありません。**

現在の対応範囲は[日本語](ja/supported-features.md)／[English](en/supported-features.md)の対応状況、編集契約は[DRMD Markdown仕様](DRMD_MARKDOWN_SPEC.md)と[AI編集ルール](DRMD_AI_EDITING_RULES.md)を参照してください。

## v0.1.2で変わったこと

v0.1.2では、往復編集に必要な情報をMarkdownと隣接サイドカーの組として扱い、画像を一般的なMarkdownビューアで確認しやすくしました。

- 復元用サイドカーの名前を`<base>.drmd`へ統一しました。
- `.drmd`は、表示・バージョン管理向けのディレクトリ形と、持ち運び向けのzip形を扱います。
- `.drmdpkg`はMarkdownとディレクトリ形サイドカーをまとめるバンドルとして残しました。
- 画像参照を相対パスに統一し、VS CodeやGitHubでディレクトリ形を開いたときに表示できるようにしました。
- XLSX画像は、取得できる場合に行・列順と表示寸法を反映します。
- Markdownで直接表示できないTIFF／EMF／WMFは元資産を保持し、プレースホルダーで知らせます。
- 画像の代替テキストは、文書内の説明、タイトル、名前、既定名の順で利用します。

## 容器の種類

| 形式 | 内容 | 主な用途 |
| --- | --- | --- |
| `<base>.md` + `<base>.drmd/` | Markdownとディレクトリ形サイドカー | 表示、編集、バージョン管理 |
| `<base>.md` + zip形`<base>.drmd` | Markdownと単一ファイルのサイドカー | 持ち運び |
| `<base>.drmdpkg` | Markdownとサイドカーを含むバンドル | 一括受け渡し |

ディレクトリ形とzip形でMarkdown内の`roundtrip_store`と画像参照は変わりません。zip形の内部画像は通常のMarkdownビューアから直接表示できないため、表示・編集時は`unpack`してディレクトリ形を使います。

## 画像表示の範囲

- DOCX／PPTXの画像は、抽出できる代替テキストとともに表示します。
- XLSXでは、位置が分かる画像を対応する行付近へ配置し、同じ行の画像は列順に並べます。
- 位置が分からない画像は埋め込み画像の節へまとめます。
- crop、rotation、重なり順、セル装飾を含む完全な紙面再現は対象外です。
- 外部リンク画像は取得せず、警告を残します。

## 取り扱い上の注意

- Markdownとサイドカーは常に同じ組として保管してください。
- pack／unpack後は`verify`で整合性を確認してください。
- 往復編集は実験機能です。元文書を正本として保持してください。
- サイドカーには元文書由来の内容が含まれるため、共有前に[セキュリティとプライバシー](ja/security-and-privacy.md)を確認してください。
