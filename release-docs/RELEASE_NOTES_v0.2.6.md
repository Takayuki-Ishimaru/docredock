# DocRedock v0.2.6 Public Beta リリースノート

公開日: 2026-09-07

v0.2.6 は、Word・Excel・PowerPoint の原文に書かれたリンクや画像の記法を、普通の文字として保持する修正です。v0.2.5 で残っていた、文字列が意図せずリンクや画像参照になったり、参照先の定義行が表示から消えたりする問題を解消します。

## 主な修正

- **普通の文字をそのまま表示**: 原文の `[LABEL](...)` や Excel セルの `[x](y)` を、クリック可能なリンクに変えず文字として表示します。`![ALT](image.png)` も画像参照に変わらず、元の文字列が残ります。
- **参照リンク記法の保持**: `[REFERENCE][id]` と `[id]: ...` を本文として保持します。定義行が Markdown の参照先として処理され、表示本文から消える問題を修正しました。
- **本文と書式の保持**: 本文、見出し、表セル、装飾付きの文字に修正を適用しました。対応する本物のハイパーリンク・画像・太字・斜体・リスト、生成する Mermaid 図、OCR の詳細表示は引き続き利用できます。GUI と CLI の変換処理にも反映しています。
- **実験的な表示・往復編集**: 往復編集用 Markdown と、実験的な `render` コマンドの HTML 表示でも、エスケープした記号を文字として扱うよう改善しました。画像の説明文に角括弧やバックスラッシュが含まれる場合の保持も改善しています。
- **ハードリンクへの出力を拒否**: CLI で、出力先が入力文書と同じ実体を指すハードリンクと識別された場合は、`--force` を付けても拒否します。衝突時は終了コード 2 で失敗し、原本を変更しません。

## 更新方法

1. DocRedock を終了し、編集中の原本を保存してください。
2. 利用する OS と CPU に合う v0.2.6 の配布ファイルをダウンロードし、`SHA256SUMS` で照合して、新しいフォルダーへ展開してください。
3. 同梱の `QUICKSTART.ja.md` に従って起動してください。環境の確認には CLI の `doctor` コマンドを利用できます。

Windows、macOS、Linux の x64／ARM64 向けに GUI と CLI を配布します。

## 利用上の制約

- Public Beta です。対応範囲は[対応機能](../docs/ja/supported-features.md)と[利用ガイド](../docs/ja/user-guide.md)を参照してください。
- 閲覧用 Markdown は一方向の出力です。元の文書を保管してください。今回の修正は、各形式で未対応のリンクや図形の変換機能を追加するものではありません。
- Markdown ファイルには表示を保つためのバックスラッシュが追加されます。エスケープを解釈する Markdown ビューアーで表示してください。URL の自動リンク化など、ビューアー独自の機能によって表示が変わる場合があります。
- ハードリンクの検出は OS とファイルシステムから取得できるファイル識別情報に依存します。識別情報を取得できない場合は、従来のパスとシンボリックリンクの照合を行います。
- 往復編集、復元、CLI の PDF 変換、新規文書生成は引き続き実験機能です。`DOCREDOCK_ENABLE_EXPERIMENTAL=1` による有効化が必要です。[実験機能の説明](../docs/ja/experimental-features.md)を参照してください。
- 配布ファイルの署名状態は、各パッケージ直下の `SIGNING-STATUS.json` を確認してください。
