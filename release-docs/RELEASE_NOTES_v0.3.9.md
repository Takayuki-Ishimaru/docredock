# DocRedock v0.3.9 Public Beta

[English](RELEASE_NOTES_v0.3.9.en.md)

v0.3.9では、PDFの読み順・段落・表の変換、Wordのコードとグラフ値の保持、CLIとGUIの使いやすさを改善しました。

## PDFの本文と表を読みやすく

- 位置と字幅から続きの行と判断できる本文を、折り返し段落としてまとめます。見出し・リスト・表・図のラベルや、判断できない行は分けて保持します。
- 段間の余白を継続して確認できる場合に、狭い段間の段組みを読み分けます。短いラベル間の空白だけで段組みとは判断しません。
- 明確な矩形の罫線格子がある表では、列幅が不均等な場合や、行・列方向に結合されたセルがある場合の再構成を改善しました。曖昧な格子の完全な再現は保証しません。
- 全文の閲覧用Markdownでは、隣接ページの端にある表で列位置と繰り返し見出しが一致し、重なる図形などがない場合に限り、続きの表をまとめます。AI向けパッケージの`document.md`にもこの表示が適用されますが、分割本文は引き続きPDFのページ単位です。

PDFの細かなベクターパス一覧と診断は`report.json`に整理し、意味のある未解決の線のラベルと線種の注記は本文に残します。照合用のページ画像をOCRに渡して本文を重複させる問題を修正しました。OCRを有効にした場合の埋め込み画像の認識は引き続き利用できます。

## Wordのコードとグラフ値の保持

連続するWordのコード段落を一つのコードブロックにまとめ、字下げと空行を保持します。グラフのカテゴリ名が不足している場合も、保存されている系列の値を欠落させずに表へ出力します。元ファイルに保存されていない値を補うことはありません。

## CLIとGUIの操作・表示

CLIでWordの最終版（`--revisions final`）を書き出した際、除外した変更履歴が存在するだけで警告終了になる問題を修正しました。CLI・GUI・APIの既定は、従来どおり`visible`／`complete`では履歴付き、`sanitized`では最終版です。履歴付きで出力する場合は、削除した内容を含む可能性があるため共有前に確認してください。

CLIのパッケージ操作とレポートのJSON出力で、日本語などの文字を読みやすく表示します。JSONのフィールド名と値の意味は変わりません。

GUIの書き出しショートカットを有効にしました。Windows／Linuxでは`Ctrl+Enter`、macOSでは`⌘+Enter`です。書き出しが可能な状態で利用でき、テキスト入力欄や選択欄の編集中には実行しません。完了・要確認・失敗の表示と、確認が必要な線・図形の案内も日本語で分かりやすくしました。

## AI向けパッケージの概算トークン数

数字の連続とMarkdown表の区切り記号を区別して見積もるよう変更しました。新しく出力したパッケージでは、同じ内容でも概算値が以前より大きくなる場合があります。分割サイズの指定は引き続き文字数で、トークン上限を指定するものではありません。既存パッケージに保存された値は、読み取り・検索時に再計算しません。

概算値はモデル固有のtokenizerによる計測ではなく、AIのトークン上限内に収まることを保証しません。CLIの`--token-estimate-multiplier`とAPIの倍率指定は引き続き利用できます。GUIには倍率の指定操作はありません。

## 互換性と利用上の制約

既存のコマンドとパッケージ形式を引き続き利用できます。manifestはschema `2.2`、`report.json`はschema `1.2`のままです。schema `1.0`／`2.0`／`2.1`の既存パッケージも引き続き読み取れます。

Public Betaです。閲覧用MarkdownとAI向けパッケージは一方向の出力で、元文書を正本として保持してください。共有前に本文、画像、診断、`review.md`を確認してください。確認事項が検出されなかったことは、変換の正しさを保証しません。

デスクトップGUIのPDF入力は既定で利用できます。CLIのPDF変換には引き続き`DOCREDOCK_ENABLE_EXPERIMENTAL=1`が必要です。往復編集、元形式への復元、PDF／Officeの新規生成は実験機能です。OCR・PDF照合画像には、利用環境に応じたproviderやrasterizerの構成が必要です。図やSmartArt、複雑なレイアウトの完全再現は保証しません。

## 配布物と更新方法

GitHub Releaseで、OS／CPUに合うアーカイブを選んでください。

| OS | CPU | ファイル名 |
| --- | --- | --- |
| Windows | Intel／AMD 64-bit | `DocRedock-v0.3.9-win-x64.zip` |
| Windows | Arm64 | `DocRedock-v0.3.9-win-arm64.zip` |
| macOS | Intel | `DocRedock-v0.3.9-osx-x64.zip` |
| macOS | Apple Silicon | `DocRedock-v0.3.9-osx-arm64.zip` |
| Linux | Intel／AMD 64-bit | `DocRedock-v0.3.9-linux-x64.tar.gz` |
| Linux | Arm64 | `DocRedock-v0.3.9-linux-arm64.tar.gz` |

ダウンロード後は`SHA256SUMS`でチェックサムを照合し、展開したフォルダーの`QUICKSTART.ja.md`を参照してください。別途.NET SDKは不要です。署名・notarizationの適用状況は、各パッケージの`SIGNING-STATUS.json`を確認してください。署名済みとは限りません。既存の文書と出力を保管したうえで、アプリを終了して新しいパッケージへ置き換えてください。
