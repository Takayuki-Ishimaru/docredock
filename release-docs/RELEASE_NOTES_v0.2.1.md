# DocRedock v0.2.1 Public Beta リリースノート

公開日: 2026-09-01

v0.2.1は、v0.2.0の実文書評価で見つかった変換品質と配布導線の不足を修正する更新です。v0.2.0を利用している方には更新を推奨します。

## 主な変更

- GUI上部に実行中バージョンを常時表示します。起動時にPublic Betaを含む非draftの公開版をバックグラウンド確認し、「更新を確認」から手動確認もできます。更新は自動インストールしません。
- PDFの規則的な表罫線をコネクタ推定から除外し、矢印先端と線分の対応を一意に保持します。方向を確定できない線は無向線と専用診断で残します。
- PPTXの斜めコネクタを座標変換後の実端点で判定し、edge labelを線分への距離と線分上の位置から保守的に対応付けます。
- XLSXで数式の保存済み計算値がない場合と、旧形式コメントを本文へ展開できない場合をWarningで明示します。外部リンクの安全なスキップはInformationとして扱います。
- 同一診断を安定して集約し、GUIでは主要診断を日本語の要約・件数・対処付きで表示します。
- すべての配布物に`docredock`起動ラッパー、版固有リリースノート、利用ガイド、対応機能、セキュリティ文書を収録します。Linuxにはユーザー領域向け`install.sh`／`uninstall.sh`を追加しました。

## 更新方法

1. アプリ上部の現在バージョンを確認し、「更新を確認」を選びます。
2. 更新がある場合は信頼済みGitHubリリースページを開き、OS／CPUに合うパッケージを取得します。
3. `SHA256SUMS`と`SIGNING-STATUS.json`を確認します。
4. 元文書と必要な出力を保持したまま、旧パッケージを新しいパッケージへ置き換えます。Linuxのユーザー領域導入では、新しい展開先から`./install.sh`を再実行します。

起動時確認を行わない場合は、起動前に`DOCREDOCK_DISABLE_UPDATE_CHECK=1`を設定してください。オフラインやAPI制限で確認に失敗しても、起動と変換は継続します。

## 既知の制約

- Readable Markdownは一方向出力です。元Office図形やPDFレイアウトの完全復元は保証しません。
- `safe`でも一意に確定できない接続・方向・ラベルはMermaidへ確定せず、代替表示と診断へ残します。
- 画像PDFのOCRには利用可能なrasterizerとOCR providerが必要です。利用できない構成ではGUI上でOCRを無効化し、理由を表示します。
- Officeへの復元、編集済みPDFの生成、新規文書生成は引き続き実験機能です。
