# DocRedock v0.2.7 Public Beta リリースノート

v0.2.7 は、工程表を閲覧用Markdownへ変換したときの矢印・期間バーの表示、日本語OCR、文字の保持を改善する更新です。

## 主な改善

- **工程表の矢印と期間バーを表の中に表示**: Word・Excel・PowerPoint・PDFの対応する表に重なる矢印、バー、マーカーなどを、該当セルの `━━▶`、`━━`、`◆` などの記号として出力します。表と図形が分かれて読みにくくなる問題を改善しました。対応条件は形式ごとに異なります。
- **図形で作られたPowerPointの工程表**: 見出しや行ラベルの矩形と、その上に置かれた矢印・バーなどから成る対応レイアウトを、閲覧用Markdownの表として出力します。通常のカード配置をすべて表に変換するものではありません。
- **PDFの工程表を認識しやすく**: 矢印や塗りつぶし図形が重なる規則的な罫線表でも、対応する構造を表として出力できるよう改善しました。認識が難しい内容は、引き続き代替表示や診断で確認してください。
- **日本語OCRの空白と利用環境の案内**: 認識した日本語の文字間に不要な空白が入るのを抑えます。GUIではPDF rasterizerが見つからない場合でも、利用可能なOCRをOffice文書内の画像に使えます。WindowsのOCR言語機能の不足や導入方法も確認しやすくしました。
- **実験的なMarkdown生成の文字保持**: `render`で `&amp;`、`&copy;`、数値文字参照などを扱う規則を出力形式間で統一しました。コード内の文字参照や、不明な参照は元の記述を保持し、HTMLタグを表す文字列が意図せずタグとして処理されるのを防ぎます。
- **実験的なWordの往復編集**: 入れ子表のセル本文を、外側の表と同時に編集して復元できるよう改善しました。既存の行・セル・段落構造を維持する本文編集が対象です。

## 更新方法

1. DocRedockを終了し、編集中の原本を保存してください。
2. OSとCPUに合うv0.2.7の配布ファイルをダウンロードし、`SHA256SUMS`で照合して、新しいフォルダーへ展開してください。
3. 同梱の `QUICKSTART.ja.md` に従って起動してください。OCRなどの利用環境はCLIの `doctor` コマンドで確認できます。

Windows、macOS、Linuxのx64／ARM64向けにGUIとCLIを配布します。

## 利用上の制約

- Public Betaです。対応範囲は[対応機能](../docs/ja/supported-features.md)と[利用ガイド](../docs/ja/user-guide.md)を参照してください。
- 閲覧用Markdownは一方向の出力です。工程表の記号は読み取り用の表現であり、元の図形や文書レイアウトを完全に再現するものではありません。元文書を保管し、変換後の表・診断・画像を確認してください。
- Wordでは図形の配置基準、Excelでは見出し・行ラベルとセル範囲、PowerPointでは表や矩形の配置、PDFでは罫線や図形の構造によって認識できる範囲が異なります。すべての工程表・ガントチャートに対応するものではありません。
- OCRには利用可能なOCRエンジンが必要です。PDFページを画像化してOCRする場合はPDF rasterizerも必要です。Tesseract、追加のOCR言語データ、pdftoppm／mutoolは同梱しません。
- GUIのPDF入力は既定で利用できます。CLIのPDF変換、往復編集、復元、新規文書生成は引き続き実験機能で、`DOCREDOCK_ENABLE_EXPERIMENTAL=1` による有効化が必要です。[実験機能の説明](../docs/ja/experimental-features.md)を参照してください。
- `.drmd`／`.drmdpkg`には元文書や復元用データが含まれる場合があります。元文書と同じ機密区分で扱ってください。
- 配布ファイルの署名状態は、各パッケージ直下の `SIGNING-STATUS.json` を確認してください。
