# DocRedock v0.2.2 Public Beta リリースノート

公開日: 2026-09-04

v0.2.2は、PDFの図と表、XLSXの診断とシート選択、CLIの診断表示を改善する品質更新です。v0.2.1を利用している方には更新を推奨します。対応機能の範囲に変更はありません。

## 主な変更

- PDFでは、セル内に文字を持つ規則的な表罫線をコネクタとして扱わないよう改善しました。タグのない格子を配置から表と判断した場合は診断で通知します。一方、片方向だけが規則的な格子や図形に接する線は、表と決めつけず確認可能な形で保持します。
- PDFフロー図の矢印先端と線分の対応を改善し、複数の矢印でも方向を保持しやすくしました。`YES`／`NO`などの分岐ラベルを線のラベルとして保持し、文字を内包する三角形は図形ノードとして扱います。
- 複雑なPDF図形の解析に時間と処理量の上限を適用し、上限に達した場合は途中の推測結果を使わず、代替表示と診断を残します。
- XLSXでは、数式の保存済み計算結果が存在しない場合だけでなく、空または空白だけの場合もWarningで通知します。DocRedockは数式自体を計算しないため、必要に応じて表計算ソフトで再計算して保存してください。
- `--sheets`で対象シートを選んだ場合、診断、非表示内容の件数、画像assetも選択範囲だけを対象にします。選択していないシートの画像は出力しません。
- CLIの診断は、既定ではコードごとに1行へ集約します。`--verbose`を指定すると個別の内容と位置情報を確認できます。
- 日本語・英語READMEのプロジェクトバナーとアプリアイコンを復旧しました。

## 更新方法

1. アプリ上部の現在バージョンを確認し、「更新を確認」を選びます。
2. 信頼済みGitHubリリースページから、OS／CPUに合うv0.2.2パッケージを取得します。
3. 公開された`SHA256SUMS`と、パッケージ内の`SIGNING-STATUS.json`を確認します。
4. 元文書と必要な出力を保持したまま、旧パッケージを置き換えます。Linuxのユーザー領域導入では、新しい展開先から`./install.sh`を再実行します。

## 既知の制約

- Readable Markdownは一方向出力です。元Office図形やPDFレイアウトの完全復元は保証しません。
- `safe`でも一意に確定できない接続、方向、ラベルはMermaidへ確定せず、代替表示と診断へ残します。
- 画像PDFのOCRには利用可能なrasterizerとOCR providerが必要です。利用できない構成ではGUI上でOCRを無効化し、理由を表示します。
- Officeへの復元、編集済みPDFの生成、新規文書生成は引き続き実験機能です。
