# セキュリティとプライバシー

日本語 | [English](SECURITY_AND_PRIVACY.en.md)

## ローカル処理

DocRedock の組み込み文書処理はローカルで動作し、文書をリモートサービスへアップロードしません。外部 URL を取得せず、表計算の数式を実行せず、環境全体からプラグインを自動探索しません。

利用者が別途導入して明示的に指定する Tesseract、Mermaid CLI、PDF ラスタライザーなどの外部プログラムは DocRedock の配布物ではありません。それらの安全性、設定、通信の有無は各提供元の情報を確認してください。

## 生成物に含まれる情報

公開・送信前に、次の点を必ず確認してください。

- .drmd ディレクトリ、zip 形式の .drmd、.drmdpkg には、復元用の元文書バイナリ、抽出グラフ、座標、資産、診断レポートが含まれます。元文書と同じ機密区分で扱ってください。
- Readable Markdown にも本文、メタデータ、保存済みの計算結果、画像、OCR 抽出テキストが含まれる場合があります。
- --embed-images を使うと画像が data URI として Markdown 本文へ入るため、ファイルを一つだけ共有しても画像は共有されます。
- OCR は画像内の非表示または小さな文字も抽出する可能性があります。
- diff、export-report、restore-report などの診断ファイルにも文書構造や一部内容が含まれる場合があります。

## 信頼できない入力

DocRedock は XML DTD、アーカイブ traversal、過大展開、symlink escape、過大な worker request、不審な数式、PDF の資源枯渇などを信頼境界で検査します。対応外または保護された Office 構造は、黙って単純化せず拒否または診断します。

主な入力上限は次のとおりです。

- 元文書: 200 MiB
- Markdown: 16 MiB
- restore 対象: 496 MiB
- 埋め込み可能な検証済み画像: 1 件 10 MiB、合計 50 MiB

上限内であっても、信頼できない文書は隔離された利用者権限で処理し、出力を開く前にウイルス対策や組織の文書検査を実施してください。

## 往復編集の完全性

- Markdown 単体では元文書を復元できません。対応する .drmd または .drmdpkg を保持してください。
- 既定では出力パスを上書きしません。--force は意図的な置換時だけ使用してください。
- verify に失敗した状態で restore を実運用へ使わないでください。
- diff で意図しない node、delete、形式変更がないことを確認してください。
- 復元後は対象 Office アプリケーションで開き、変更箇所とレイアウトを目視確認してください。

これらの検査は、文書内容の正しさ、外部プログラムの安全性、またはすべての悪意ある入力への完全な防御を保証するものではありません。

## OCR とプライバシー

macOS の Apple Vision、Windows の Windows.Media.Ocr、ローカルの Tesseract fallback は端末上で使用します。Tesseract の言語モデルは利用者が別途導入します。OS 管理機能や外部実行ファイルのログ、クラッシュレポート、組織ポリシーについては利用環境側の設定も確認してください。

## 脆弱性の報告

機密性のある脆弱性情報、攻撃用サンプル、実文書を公開 Issue に投稿しないでください。公開リポジトリで Private vulnerability reporting が有効な場合は、その非公開報告機能を使用してください。利用できない場合は、リリースページまたはリポジトリの SECURITY.md に記載された保守者の非公開連絡先を使用してください。

一般公開前に、保守者は Private vulnerability reporting を有効化し、ルートの SECURITY.md に対象バージョン、初動目安、連絡方法を記載する必要があります。

## 依存関係とライセンス

解決済み依存関係は packages.lock.json で固定し、licenses/allowlist.json と LicenseAudit で検査します。一般配布物には LICENSE、THIRD-PARTY-NOTICES、SBOM を同梱し、リリースごとに依存関係と許可ライセンスを再確認してください。
