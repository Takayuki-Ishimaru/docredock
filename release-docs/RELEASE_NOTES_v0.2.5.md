# DocRedock v0.2.5 Public Beta リリースノート

公開日: 2026-09-07

v0.2.5 は、入力ファイルの保護と、Word・Excel・PowerPoint・PDF から Markdown へ変換するときの内容保持を改善する更新です。Word の入れ子表では、本文、段落内の改行、内側の表、後続の本文の順序も保持します。

## 主な修正

- **原本の上書き防止**: 入力ファイルと同じファイルを出力先に指定した場合、`--force` を付けても変換を拒否します。Word・Excel・PowerPoint・PDF に共通の保護です。
- **Word の非表示文字**: 文字スタイル、段落スタイル、既定スタイルから継承した非表示設定を反映し、`visible`／`sanitized` で対象の文字を除外します。
- **PowerPoint の非表示グループ**: 親グループの非表示設定を子要素へ反映します。入れ子のグループ内の文字も対象です。
- **Word のコンテンツコントロール**: ブロック型のコンテンツコントロール内の本文を、前後の内容と同じ順序で抽出します。
- **Word の数式**: ネイティブ数式を線形テキストへ変換して保持します。たとえば E=mc² は `E=mc^2` として出力され、元の数式組版を再現していないことを `DocxMathLinearized` 警告で知らせます。
- **PDF の混在画像**: 通常の文字と画像が同じページにある場合も、OCR とラスタライザーを利用できる条件では、画像領域の切り出しと画像内の文字の認識を行います。画像を抽出できない場合は、位置を示す代替表示と警告を残します。
- **Markdown の記号**: 原文の強調記号、HTML タグ、バッククォートなどをエスケープし、後続の本文や表が意図せず構文として解釈される問題を修正しました。往復編集用 Markdown にも反映しています。
- **Excel の表示形式**: ゼロ埋め、縮尺付き数値、指数表記、工学表記、分数、条件付き書式指定の処理を改善しました。たとえば `000000` の 123 は `000123`、`#,##0.0,,` の 1234567 は `1.2` として出力します。
- **Word・PowerPoint の表**: 表セル内の段落境界と改行を保持します。Word の入れ子表は親セル内に順序を保って展開し、前後の本文や段落内の改行を保持します。PowerPoint の結合セル内でも段落の区切りを保持します。
- **PowerPoint のマスター由来の文字**: スライドマスターとレイアウト上の可視文字を取り込みます。プレースホルダーの重複や非表示設定を考慮します。
- **PDF の本文保持**: 図のノード名と同じ文字列でも、図の外にある見出しや本文を残します。`START` などが図のラベルと誤判定されて消える問題を修正しました。
- **PDF の段組み**: 左右で行間が異なる文書の読み順を改善し、フッターが右段の本文より先に出る問題を修正しました。
- **PDF の複数の表**: 独立した表の罫線を図の接続線と誤判定し、存在しない接続関係の警告が出る問題を修正しました。

## 実験的な往復編集

Word のコンテンツコントロール、数式を含む段落、本文中のテキストボックスの取り扱いを改善しました。線形化した数式を変更しない場合は元の数式を保持します。数式を書き換えた場合や、コンテンツコントロールの境界を変更する場合には、表現や構造の変更について警告します。

往復編集は引き続き実験機能です。[実験機能の説明](../docs/ja/experimental-features.md)を確認し、出力を原本と照合してください。

## 更新方法

1. DocRedock を終了し、編集中の原本を保存してください。
2. 利用する OS と CPU に合う v0.2.5 の配布ファイルをダウンロードし、`SHA256SUMS` で照合して、新しいフォルダーへ展開してください。
3. 同梱の `QUICKSTART.ja.md` に従って起動してください。環境の確認には CLI の `doctor` コマンドを利用できます。

Windows、macOS、Linux の x64／ARM64 向けに GUI と CLI を配布します。

## 利用上の制約

- Public Beta です。対応範囲は[対応機能](../docs/ja/supported-features.md)と[利用ガイド](../docs/ja/user-guide.md)を参照してください。
- 読み取り用 Markdown は片方向の出力です。元の文書を保管してください。
- 数式の線形化や入れ子表の展開は内容保持を目的とし、原文の組版や表の配置をそのまま再現するものではありません。
- PDF の画像処理には OCR とラスタライザーが必要です。回転した画像や複雑なレイアウトなどは処理できない場合があり、その場合は警告を確認してください。
- PDF から Markdown への変換は GUI で利用できます。CLI の PDF 変換や文書の新規生成は実験機能で、`DOCREDOCK_ENABLE_EXPERIMENTAL=1` による有効化が必要です。詳細は[対応機能](../docs/ja/supported-features.md)を参照してください。
- 配布ファイルの署名状態は、各パッケージ直下の `SIGNING-STATUS.json` を確認してください。
