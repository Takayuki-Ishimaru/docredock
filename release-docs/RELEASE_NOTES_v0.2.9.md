# DocRedock v0.2.9 Public Beta リリースノート

v0.2.9は、PDF工程表の両矢印の保持と、変換しきれない図形の確認方法を改善する更新です。OCRの照合情報も本文の読み順にそろえ、必要な量を選んで表示できるようにしました。

## 主な改善

- **PDF工程表の両矢印を保持**: 横方向・縦方向の両矢印で、片方の先端が消えたり、PDF内の描画順によって向きが変わったりする問題を修正しました。先端がセル内に少しだけ入る場合も、その先端があるセルに記号を表示します。
- **表を横断する斜め線の見落としを防止**: 表内の記号として表現できない斜め線・斜め矢印を、変換済みとして黙って取り除かず、確認が必要な図形として警告します。原本照合用画像を有効にし、PDF rasterizerが利用できる場合は、ページ画像も添付します。
- **原本照合用画像の添付漏れを修正**: 図として再構成できず、線や図形のパス情報だけが残るページも画像添付の対象にしました。画像を生成できない場合は、そのページの診断で知らせます。OCRがオフでも動作し、GUIの設定またはCLIの`--pdf-fallback-images auto|off`で切り替えられます。
- **表の不要な警告を削減**: 見出しの背景塗りと矩形の外枠がある表で、セルの文字を図のラベルとして扱ったことによる不要な警告を減らしました。
- **確認が必要な件数を分かりやすく表示**: 書き出し結果に、要確認ページ数、照合画像を添付したページ数、未解決の視覚要素数を分けて表示します。画像が付いたことと、図形の内容を変換できたことを区別して確認できます。
- **OCR照合情報の読み順と表示量を改善**: 照合情報を本文と同じ行順・行内の順序にそろえ、行番号を追加しました。GUIの「OCR照合情報の詳細」、CLIの`--ocr-review low-confidence|all|summary`から表示量を選べます。

## OCR照合情報の既定表示の変更

閲覧用Markdownでは、既定で信頼度80%未満または信頼度不明の項目だけを詳細表示します。全件を確認する場合は`all`、件数だけを確認する場合は`summary`を選択してください。どの設定でもOCR本文と原画像を保持します。実験的なaudit／roundtripのサイドカーは全件の記録を保持します。

信頼度はOCRエンジンの推定値であり、正解率ではありません。識別子、品番、数値を推測で自動修正することはありません。

## 更新方法

1. DocRedockを終了し、編集中の原本を保存してください。
2. OSとCPUに合うv0.2.9の配布ファイルをダウンロードし、`SHA256SUMS`で照合して、新しいフォルダーへ展開してください。
3. 同梱の`QUICKSTART.ja.md`に従って起動してください。OCRやPDF rasterizerの利用環境は、CLIの`doctor`コマンドで確認できます。

Windows、macOS、Linuxのx64／ARM64向けにGUIとCLIを配布します。

## 利用上の制約と注意点

- Public Betaです。対応範囲は[対応機能](../docs/ja/supported-features.md)と[利用ガイド](../docs/ja/user-guide.md)を参照してください。任意のPDF図形や工程表を完全に再構成できるわけではありません。
- 閲覧用Markdownは一方向の出力です。斜め線・斜め矢印の意味や接続先を自動的に確定する更新ではありません。未解決の警告がある場合は、照合画像や元文書を確認してください。画像を添付しても警告は解消されません。
- PDFページの画像化にはPDF rasterizer、OCRには利用可能なOCRエンジンが必要です。Tesseract、追加のOCR言語データ、pdftoppm／mutoolは同梱しません。OCRの位置リンクによる領域表示は閲覧ソフトの対応に依存します。
- GUIのPDF入力は既定で利用できます。CLIのPDF変換、往復編集、復元前チェック、復元、新規文書生成は実験機能で、`DOCREDOCK_ENABLE_EXPERIMENTAL=1`による有効化が必要です。[実験機能](../docs/ja/experimental-features.md)を参照してください。
- 元文書を正本として保持してください。サイドカーや原本照合用画像には元文書の内容が含まれます。共有時の扱いは[セキュリティとプライバシー](../docs/ja/security-and-privacy.md)を参照してください。
- 配布ファイルの署名状態は、各パッケージ直下の`SIGNING-STATUS.json`を確認してください。
