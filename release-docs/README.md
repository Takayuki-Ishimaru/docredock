## v0.1.4 Public Beta

- サポート: DOCX／XLSX／PPTXから閲覧用Markdownへのローカル変換。
- 安全な既定値: `visible`。`complete`は非表示情報を警告付きで含み、`sanitized`はより強く除外。
- 実験機能: PDF、往復編集、復元、生成、パッケージ操作は`DOCREDOCK_ENABLE_EXPERIMENTAL=1`が必要。
