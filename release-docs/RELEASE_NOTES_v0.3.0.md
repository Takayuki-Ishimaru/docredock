# DocRedock v0.3.0 Public Beta

[English](RELEASE_NOTES_v0.3.0.en.md)

v0.3.0は、変換した文書をAIへ渡すための**AI向けパッケージ**を追加し、Word・Excel・PowerPointの読みやすさとPDFの確認表示を改善します。

## AI向けパッケージ

GUIで「AI向けパッケージ」を選び、フォルダーまたはZIPに書き出せます。CLIでは次のコマンドを使います。

```sh
docredock export input.docx --ai-package zip
```

パッケージには、全文のMarkdown、意味のまとまりごとの分割、参照画像、確認事項（`review.md`）、出典とファイルのハッシュをまとめます。変換はローカルで完結し、パッケージ生成で文書をアップロードしません。APIでは`DocumentService.ExportAiPackageAsync`を利用できます。

Wordは見出しと意味のまとまりで分割し、PDFはページ、PowerPointはスライド、Excelはシートごとに保持します。表・入れ子の表・図の構成要素・連続するリストを途中で切りません。大きい単位はサイズの目安を超える場合があり、確認事項に記録します。文字数の目安であり、AIモデルのトークン上限ではありません。出典には実際のページ・スライド・シート・見出しを使い、Wordのページ番号は推測しません。

対象内容の設定とExcelのシート選択をパッケージ全体に適用します。`complete`で非表示内容を含む場合は共有前の確認を表示します。元文書と元ファイルの絶対パスは同梱しませんが、元ファイル名・ハッシュと変換した内容は含まれます。共有前に全文、画像、`review.md`を確認してください。

失敗・キャンセル時は不完全なパッケージを残さず、CLIの`--force`は変換成功後に既存出力を置換します。GUIで繰り返し書き出す場合は連番の名前を使います。画像はパッケージの`assets/`に保存するため、CLIの`--embed-images`とは併用できません。パッケージは一方向出力で、復元用サイドカーではありません。

## 文書の読みやすさと確認表示

- Excelで行見出しと数値が空白列により分断される問題を改善し、予約表などの隣にある候補リストを別のまとまりとして扱います。多段ヘッダーは階層付きの列名へ整理します。
- PowerPointの図形・接続ラベルで2行目以降が欠落する問題を修正し、矢印や接続先を持たない目次の装飾点線が図として出力される問題を抑えます。
- Wordのグラフに保存されたカテゴリと数値をMarkdown表として出力します。外部データの取得や埋め込みブックの数式評価は行わず、保存済みデータを取得できない場合は警告と代替表示を残します。
- Wordの独自IDの見出しスタイルや、直接書式のタイトル・章を限定的に認識します。画像の表示サイズを保持し、サイズ指定画像にはHTMLの`img`タグを使います。HTML画像に対応するMarkdownビューアーで確認してください。
- PDFのクリップ専用パスによる不要な図形警告・照合画像を抑えます。原本照合の必要性と、非表示内容を含む場合の共有前確認を区別して表示します。

## 利用上の制約と配布物

Public Betaのため、本番向けの安定版ではありません。PDF／Office変換や図の推定に関する既存の制約は継続し、変換結果だけで原本の意味を完全に保持したと判断しないでください。OCRとPDF照合画像には、利用環境に応じてOCR providerやrasterizerの構成が必要です。

デスクトップGUIのPDF入力は既定で利用できます。CLIのPDF変換には引き続き`DOCREDOCK_ENABLE_EXPERIMENTAL=1`が必要です。往復編集、元形式への復元、PDF／Officeの新規生成も実験機能です。

配布対象はWindows（x64／Arm64）、macOS（Intel／Apple Silicon）、Linux（x64／Arm64）です。公開時のGitHub ReleaseでOS／CPUに合う配布物と`SHA256SUMS`を確認してください。各パッケージの`SIGNING-STATUS.json`に署名・notarizationの適用状況を記録します。署名済みとは限りません。

詳しい手順は[利用ガイド](../docs/ja/user-guide.md)、対応範囲は[対応機能](../docs/ja/supported-features.md)、APIとJSONの契約は[AI向けパッケージ形式仕様](../docs/reference/ai-package.md)を参照してください。
