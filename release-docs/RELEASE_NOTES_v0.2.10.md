# DocRedock v0.2.10 Public Beta リリースノート

v0.2.10は、変換しきれなかった内容を確認しやすくし、対応する表上の図形の線種（実線・破線・点線）を保持する更新です。PDFでの不要な警告や図形の二重表示も修正しました。

## 主な改善

- **表に重なる図形の線種を保持**: PDF、PowerPoint、Excel、Wordの対応する表上の矢印・バー・線について、破線と点線を実線と区別して閲覧用Markdownへ出力します。線種に応じた記号と、図形の種類や行・列の範囲を示す注記で確認できます。Mermaidの図では、破線・点線の接続を点線で表し、元の線種を注記します。
- **表の外の見出しによる不要な警告を解消**: 表の外枠を1つの矩形で描いたPDFで、表の外にある見出しなどの文字が図のラベルとして警告される問題を修正しました。同じページにある図の本当に曖昧なラベルの警告は残ります。
- **塗りと枠を別々に描いた図形の二重表示を修正**: 塗りつぶしと枠線を別々に描いたPDFのバーなどが、同じセルに2つの記号として表示される問題を修正しました。
- **書き出し結果の表示を整理**: Markdownの保存結果、認識した図の要素の変換状況、人の確認が必要な箇所を分けて表示します。CLIでは、要確認ページごとに確認する内容と、利用できる場合は照合画像の場所を表示します。
- **OCRの確認対象をわかりやすく表示**: 認識の信頼度が低い、または不明なOCR結果の確認件数を、警告とは別に表示します。この件数だけでCLIの終了コードが変わることはありません。
- **GUIの確認手順を短縮**: 結果画面に確認が必要なページや図形と、その理由を短い説明で表示します。詳しい診断は折りたたみ表示にまとめました。「該当ページを確認」から、PDFの原本ページ画像と、そのページのMarkdownを並べて確認できます。位置がわかる未変換の線や図形は赤い線や枠で示します。

## 更新方法

1. DocRedockを終了し、編集中の原本を保存してください。
2. OSとCPUに合うv0.2.10の配布ファイルをダウンロードし、`SHA256SUMS`で照合して、新しいフォルダーへ展開してください。
3. 同梱の`QUICKSTART.ja.md`に従って起動してください。OCRやPDF rasterizerの利用環境は、CLIの`doctor`コマンドで確認できます。

Windows、macOS、Linuxのx64／ARM64向けにGUIとCLIを配布します。

## 利用上の制約と注意点

- Public Betaです。対応範囲は[対応機能](../docs/ja/supported-features.md)と[利用ガイド](../docs/ja/user-guide.md)を参照してください。任意のPDF図形や工程表を完全に再構成できるわけではありません。
- 線種は実線・破線・点線を区別します。一点鎖線などは破線として扱い、色、線の太さ、凡例の意味は保持しません。保持する範囲は対応機能の「線種など視覚属性の保持範囲」を参照してください。
- 閲覧用Markdownは一方向の出力です。斜め線・斜め矢印の意味や接続先を自動的に確定する更新ではありません。未解決の警告がある場合は、照合画像や元文書を確認してください。画像を添付しても警告は解消されません。
- 照合画面の原本ページ画像はPDFが対象で、書き出し時に添付された照合画像が必要です。画像がない場合やOffice文書の場合は、案内に従って元文書を確認してください。PDFページの画像化にはPDF rasterizer、OCRには利用可能なOCRエンジンが必要です。Tesseract、追加のOCR言語データ、pdftoppm／mutoolは同梱しません。
- 変換状況の表示は、DocRedockが認識した図の要素についての案内です。元文書のすべての見た目や意味が保持されたことを保証するものではありません。
- GUIのPDF入力は既定で利用できます。CLIのPDF変換、往復編集、復元前チェック、復元、新規文書生成は実験機能で、`DOCREDOCK_ENABLE_EXPERIMENTAL=1`による有効化が必要です。[実験機能](../docs/ja/experimental-features.md)を参照してください。
- 元文書を正本として保持してください。サイドカーや原本照合用画像には元文書の内容が含まれます。共有時の扱いは[セキュリティとプライバシー](../docs/ja/security-and-privacy.md)を参照してください。
- 配布ファイルの署名状態は、各パッケージ直下の`SIGNING-STATUS.json`を確認してください。
