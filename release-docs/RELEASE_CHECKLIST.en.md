# Pre-release Checklist

[日本語](RELEASE_CHECKLIST.md) | English

This document is a reusable policy template for creating a public commit/tag and every OS-specific distribution. Unchecked boxes here are not evidence that a past release skipped them. The authoritative record for each release is the completed `RELEASE-EVIDENCE.md` generated by the release workflow, including the workflow run URL, commit, and artifact hashes. Do not publish when any mandatory automated gate fails.

PDF conversion/rendering and restoration to original file formats are unsupported in v0.1.3, explicitly gated by DOCREDOCK_ENABLE_EXPERIMENTAL=1, and excluded from user-facing smoke tests. Signing and notarization are applied when configured, but the absence of a certificate alone does not block a Public Beta release. Each distribution records the applied status.

## Build and test

Run the following from a clean clone with the pinned SDK, using final paths after the rename:

```sh
dotnet restore DocRedock.sln --locked-mode
dotnet build DocRedock.sln --configuration Release --no-restore
dotnet test tests/DocRedock.Tests/DocRedock.Tests.csproj --configuration Release --no-build --no-restore
dotnet run --project tools/LicenseAudit/LicenseAudit.csproj --configuration Release -- --root . --output artifacts
```

- [ ] Restore succeeds without changing a lock file
- [ ] Release build succeeds with zero warnings and zero errors
- [ ] Every test succeeds and every skip reason has been reviewed
- [ ] If conversion-qa remains in public CI, it succeeds using only synthetic fixtures
- [ ] LicenseAudit succeeds and emits the SBOM
