# DocRedock v0.3.3 Public Beta

[English](RELEASE_NOTES_v0.3.3.en.md)

v0.3.3は、Word・Excel・PowerPoint・PDFの下線と取り消し線、PDFの文字と読み順、AI向けパッケージの読み取りを改善します。Wordの変更履歴を閲覧用出力に表示し、AIへ渡す前に確認が必要な変換結果を自動処理で検出しやすくします。

## 下線・取り消し線と表示

- Excelのセル・リッチテキスト、Word・PowerPointの表、Wordのテキストボックス・ヘッダー／フッター・脚注／文末脚注で、下線と取り消し線を保持します。Wordの文字・段落スタイルや文書の既定値から継承した装飾と、直接書式での解除も反映します。
- 文字を横切る線や下に引いた線を、対応する範囲で取り消し線・下線として読み取ります。PDFの取り消し線・下線注釈にも対応します。矢印、接続線、表の罫線は区別します。
- 下線は `<u>…</u>`、取り消し線は `~~…~~` で出力します。太字・斜体・コードと組み合わせた装飾もGUIプレビューで表示します。原文のMarkdown記号やHTML風の文字列は文字のまま保持します。
- Wordの入れ子表の内容が消える問題、Excelのセル内文字やPowerPointの書式の切り替わりで文字・空白が欠ける問題、PowerPoint表のタブ位置設定が余分なタブになる問題を修正しました。

見出し・リンクを識別する下線は強調として出力しません。線が文字の一部だけを横切り、対象文字を確定できない場合は取り消し線を推測せず照合を案内します。字幅が不明なPDFの部分的な下線は出力できない場合があります。HTMLの下線・挿入表示には、HTMLを表示できるMarkdownビューアーが必要です。

## Wordの変更履歴とExcelの条件付き書式

閲覧用MarkdownとAI向けパッケージでは、Wordの削除・移動元を `~~取り消し線~~`、挿入・移動先を `<ins>追加</ins>` で表示します。追加・削除された行やセルも表示し、書式・表の構成・段落やセクションの変更には変更前後の注記を付けます。

**共有前の確認:** Word本文の変更履歴は、既定の `visible` や `sanitized` でも表示され、削除した文字を含む場合があります。変更履歴を含めたくない場合は、原本のコピーで変更を確定してから変換してください。明示的に非表示の文字は引き続き内容ポリシーで除外します。変更前のページ組版は再現せず、実験的な往復編集では確定後の本文として扱い、変更履歴をまたぐ編集を制限します。

Excelの条件付き取り消し線は、対応する演算・論理・集計・文字列・日付関数、別シートの保存済み値、名前定義を使って判定します。セル数式の再計算は行いません。`TODAY`・`NOW` は変換開始時の端末の日時を使います。未対応の参照・関数、保存済み値の欠落などで判定できない場合は通常の書式を保持し、診断を出します。

## PDFの文字と読み順

- フォントの字幅と文字間隔を使い、書式の変わり目で語が割れる問題、語間の欠落、上付き・下付き文字が別の行になる問題を改善しました。標準フォントで字幅表が省略されている場合にも対応します。
- 文字位置の丸め誤差で見出しや表の見出しの文字順が崩れる問題、文字列のエスケープや文字コードの違いで文字が欠けたり文字化けしたりする問題を修正しました。
- 左右に並ぶ枠内の文字を枠ごとに読み、対応する段落の折り返しをつなぎます。破線で描かれた表罫線も表として読み取ります。
- 適用条件を満たすAdobe-Japan1の標準対応表、埋め込みEncoding CMap、TrueTypeの文字対応表を使って、Unicode対応表が省略されたPDFの文字を読み取ります。文字を一意に決定できない場合は推測せず、警告と原本照合の案内を残します。

罫線のない表の区切りや複雑な配置は引き続き推定です。字幅・文字対応が欠けるフォント、回転文字、未対応の文字コードなどには制約があります。フォント本体は同梱しません。

## AI向けパッケージと自動処理

大きなExcel表を行ブロックに分割すると、表のすぐ上にある短い表題・単位・条件の注記を、後続ブロックの見出し前にも再掲します。独立した表の見出しや行の対応、分割ごとの文書タイトルも改善しました。`--table-row-blocks` は引き続き任意指定で、既定では無効です。分割サイズは目安で、長い1行などは目安を超える場合があります。`estimated_tokens` は概算で、モデルの実際のトークン数や入力上限を保証しません。

**互換性:** manifest schemaは `2.1` から `2.2` へ更新し、`table_block.context_range` を追加します。`report.json` はschema `1.1` のままです。APIとPythonの読み取り例はmanifest `1.x`・`2.x` を読み、未対応のメジャーバージョンを拒否します。連携ツールは未知の追加項目を無視してください。

読み取り例とAPIは、manifest・出典情報・表ブロックのつながりを点検し、検証時にはファイルサイズ・SHA-256と未登録ファイルを確認します。不正なパス、重複項目、曖昧なZIP構造、リンクなどを拒否します。検証後に分割本文・元セル・確認状態をまとめて取得でき、語を含む分割も検索できます。従来読み取れていた不正なパッケージがエラーになる場合があります。検証に失敗した場合、`--verify --part` は本文を出力しません。ハッシュの一致は、変換の正しさや共有可否を保証しません。

`export --fail-on-review` を追加しました。原本照合ページ・OCR確認・Excelの表の区切りなどの要確認事項がある場合、出力を保存したうえで終了コード `11` を返します。指定しない場合の終了コードは従来どおりです。

```sh
docredock export input.xlsx --ai-package zip --table-row-blocks --fail-on-review
```

受け取ったパッケージのPython読み取り例では、`--verify --fail-on-review` で検証し、要確認の場合は本文を出さず終了コード `3` を返せます。詳しくは[利用ガイド](../docs/ja/user-guide.md#ai向けパッケージ)と[形式仕様](../docs/reference/ai-package.md)を参照してください。

## 利用上の制約と配布物

Public Betaであり、本番向けの安定版ではありません。閲覧用MarkdownとAI向けパッケージは一方向の出力です。元文書を正本として保持し、全文・画像・診断・`review.md` を共有前に確認してください。要確認事項が検出されなかったことは、変換の正しさを保証しません。生成はローカルで行い、生成時に文書をアップロードしません。

デスクトップGUIのPDF入力は既定で利用できます。CLIのPDF変換には引き続き `DOCREDOCK_ENABLE_EXPERIMENTAL=1` が必要です。往復編集、元形式への復元、PDF／Officeの新規生成は実験機能です。`.drmd`・`.drmdpkg` は元文書を含み得るため、元文書と同じ機密区分で扱ってください。OCR・PDF照合画像には、利用環境に応じてproviderやrasterizerの構成が必要です。図やSmartArt、複雑なレイアウトの完全再現は保証しません。

配布対象はWindows（x64／Arm64）、macOS（Intel／Apple Silicon）、Linux（x64／Arm64）です。GitHub ReleaseでOS／CPUに合う配布物と `SHA256SUMS` を確認してください。署名・notarizationの適用状況は各パッケージの `SIGNING-STATUS.json` に記録します。署名済みとは限りません。

対応範囲は[対応機能](../docs/ja/supported-features.md)、取り扱い上の注意は[セキュリティとプライバシー](../docs/ja/security-and-privacy.md)を参照してください。
