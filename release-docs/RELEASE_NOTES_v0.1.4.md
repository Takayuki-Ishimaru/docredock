# DocRedock v0.1.4 Public Beta リリースノート

リリース日: 2026-08-27

DocRedock v0.1.4は、v0.1.3に対する独立レビューを反映した変換品質・起動信頼性の更新です。利用者向けのサポート範囲は引き続き、DOCX／XLSX／PPTXから**閲覧用Markdown**へのローカルな一方向変換です。

## 主な変更

- XAML初期化中に内容ポリシーの選択イベントが早期発火していた、GUIの致命的な起動クラッシュを修正しました。
- 公開前のGUI検査を二段構えにしました。Avalonia headlessでの専用`MainWindow`構築試験に加え、LinuxではXvfb配下で実配布DocRedock GUI子プロセスが生存していることを確認します。
- XLSXのネイティブグラフを、無関係な非表示情報だけで隠さないよう修正しました。
- 独立レビューで報告されたDOCX、XLSX、PPTX、実験的HTMLの読みやすさをすべて改善しました。

## 変換品質の修正

### DOCX

- 閲覧用Markdownへ漏れていた`<span style=...>`ラッパーを除去します。
- 実験的HTMLでアンダースコア斜体を正しく描画します。
- `1. 1.`のような順序付きリスト番号の重複を防ぎます。
- Wordのリストスタイルから推定した入れ子の深さを保持します。

### XLSX

- グラフ式と参照セル範囲を解決してから、保存済みグラフデータの可視性を判定します。
- グラフの参照元と無関係な非表示シート・行・列があっても、表示対象グラフを維持します。
- 参照を解析できず、ブック内に非表示ソースがあり得る場合は、保存済みグラフデータを非表示のままにします。非表示要素のないブックでは診断付きでキャッシュを利用できます。
- 更新日や状態のメタデータ行を、隣接するデータ表・リスク表から分離します。

### PPTX

- タイトルプレースホルダーがなくても、上部にある全太字・単一段落の図形をタイトルとして推定します。
- 文字として入力された箇条書き記号をMarkdownリストへ変換します。
- 各スライド下部で繰り返されるフッターを抑制します。
- 非表示スライドを除外した場合の空見出しを出力しません。

### 実験的HTMLプレビュー

- アンダースコア斜体と8桁カラーのspanを描画します。
- MarkdownとHTMLを兄弟ディレクトリへ出力する場合を含め、画像リンクを最終HTML出力先からの相対パスへ補正します。

## 安全性と互換性

- 安全な既定値は引き続き`visible`です。`complete`は非表示情報・メタデータを警告付きで含み、`sanitized`はさらに強く除外します。
- XLSXグラフの参照が曖昧で、非表示ソースがあり得る場合は、キャッシュ内容を公開しません。
- サポート対象のCLIコマンド名と内容ポリシー名に変更はありません。
- 閲覧用Markdownは一方向出力です。元のOffice文書を正本として保持してください。

## 実験機能

PDF変換、往復編集、元形式への反映、レンダリング／新規文書生成、パッケージ操作は引き続き実験機能です。配布版GUI／CLIでは`DOCREDOCK_ENABLE_EXPERIMENTAL=1`が必要です。`.drmd`や`.drmdpkg`には元文書由来または復元用の情報が含まれる場合があります。

## 配布と検証

リリースワークフローは次の自己完結型パッケージを生成します。

- Windows x64／ARM64
- macOS x64／ARM64
- Linux x64／ARM64

公開前に、locked restore、Releaseビルド、通常の回帰試験、専用GUI構築試験、変換QA、ライセンス監査、配布物の展開、CLIスモーク試験、バイナリアーキテクチャ確認、Linux実配布GUI起動がすべて成功する必要があります。公開物にはチェックサム、SBOM／provenance、署名状況、リリース証跡を含めます。

## 更新方法

使用中のv0.1.3 GUI／CLIを、OSとCPUに合うv0.1.4パッケージへ置き換えてください。元のOffice文書を保持し、Markdownと画像は共有前に確認してください。
