# DocRedock v0.2.11 Public Beta リリースノート

v0.2.11は、PDFの描画部品（Form XObject）に含まれる文字や図が、ページの本文と同居すると警告なしに欠落していた問題を修正する更新です。照合画面には要確認箇所への拡大と、Markdownの表示切替を追加しました。

## 主な改善

- **PDFの描画部品（Form XObject）内の文字・図を保持**: ページが描画するForm XObject（PDF内で繰り返し使える描画部品。入力フォームとは別物です）の文字と図形を、ページに直接描かれた内容と同じように閲覧用Markdownへ出力します。これまでは、ページに本文があると、Form内の文字や図が警告なしに欠落していました（v0.2.9以前から発生していた問題です）。入れ子のFormと、Formの配置（変換行列）も反映します。
- **解析できない描画部品を「確認不要」にしない**: 入れ子が深すぎる、大きさが上限を超える、DocRedockが読めない形式で格納されている、などの理由で解析できない描画部品は、`PdfFormXObjectUnparsed`警告を出して要確認ページとし、PDF rasterizerがあれば照合画像を添付します。OCRを有効にすると、ページ全体のOCRでその文字を補います（本文と重複する認識結果は除きます）。
- **「解析できなかった内容」を区別して表示**: 書き出し結果に、解析できなかった内容の件数を、認識した図の要素の変換状況とは別に表示します。CLIでは`Unanalyzed content`行、GUIでは「未解析の描画部品」として表示します。
- **照合画面で要確認箇所を拡大**: 「要確認箇所へ拡大」で、強調した箇所を1件ずつ画面中央に拡大表示します。「＋」「－」、Ctrlキー（macOSではCommandキーも可）＋マウスホイールで倍率を変え、「全体」でページ全体の表示に戻れます。
- **照合画面でMarkdownを表示形式でも確認**: そのページのMarkdownを、表は罫線付きの表、Mermaidの図は「START → END（ラベル）」のような接続の一覧として表示できます。「ソース」に切り替えると、Markdownそのものを確認できます。
- **大きな画像を含むPDFの変換を軽量化**: 文字の変換表を読む際の不要な処理を減らし、大きな画像を含むPDFの変換時に使うメモリを削減しました。
- **実験的な新規文書生成の修正**: バッククォート4つ以上で囲んだコードブロック（中にバッククォート3つの行を含むもの）を、内側の行で閉じてしまう問題を修正しました。

## 更新方法

1. DocRedockを終了し、編集中の原本を保存してください。
2. OSとCPUに合うv0.2.11の配布ファイルをダウンロードし、`SHA256SUMS`で照合して、新しいフォルダーへ展開してください。
3. 同梱の`QUICKSTART.ja.md`に従って起動してください。OCRやPDF rasterizerの利用環境は、CLIの`doctor`コマンドで確認できます。

Windows、macOS、Linuxのx64／ARM64向けにGUIとCLIを配布します。

## 利用上の制約と注意点

- Public Betaです。対応範囲は[対応機能](../docs/ja/supported-features.md)と[利用ガイド](../docs/ja/user-guide.md)を参照してください。任意のPDF図形や工程表を完全に再構成できるわけではありません。
- Form XObjectの表示範囲（`/BBox`）による切り抜きと、非表示レイヤー（Optional Content）の表示状態は評価しません。画面には表示されない文字が出力される場合があります。
- 閲覧用Markdownは一方向の出力です。未解決の警告や解析できなかった内容がある場合は、照合画像や元文書を確認してください。画像を添付しても警告は解消されません。
- 照合画面の原本ページ画像はPDFが対象で、書き出し時に添付された照合画像が必要です。画像がない場合やOffice文書の場合は、案内に従って元文書を確認してください。PDFページの画像化にはPDF rasterizer、OCRには利用可能なOCRエンジンが必要です。Tesseract、追加のOCR言語データ、pdftoppm／mutoolは同梱しません。
- 照合画面の「表示」は確認用の簡易表示です。Mermaidの図は接続の一覧として示し、読み取れない図はソースのまま表示します。
- 変換状況の表示は、DocRedockが認識・解析した内容についての案内です。元文書のすべての見た目や意味が保持されたことを保証するものではありません。
- GUIのPDF入力は既定で利用できます。CLIのPDF変換、往復編集、復元前チェック、復元、新規文書生成は実験機能で、`DOCREDOCK_ENABLE_EXPERIMENTAL=1`による有効化が必要です。[実験機能](../docs/ja/experimental-features.md)を参照してください。
- 元文書を正本として保持してください。サイドカーや原本照合用画像には元文書の内容が含まれます。共有時の扱いは[セキュリティとプライバシー](../docs/ja/security-and-privacy.md)を参照してください。
- 配布ファイルの署名状態は、各パッケージ直下の`SIGNING-STATUS.json`を確認してください。
