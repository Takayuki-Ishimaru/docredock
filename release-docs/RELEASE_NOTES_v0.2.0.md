# DocRedock v0.2.0 Public Beta リリースノート

## 1. 概要

v0.2.0 は、DOCX／XLSX／PPTX／PDF から Readable Markdown への一方向変換で、図やフローの接続関係をより安全に扱います。完全な図面再現ではなく、明確に判断できる関係だけを Mermaid へ変換し、不確実な情報は元テキスト、画像・ページの代替表示、診断として残します。

## 2. 接続推定モード

- `native-only`: 元形式に明示された接続だけを使用します。
- `safe`（既定・推奨）: 明示された接続と、一意に判断できる確度の高い接続を使用します。
- `balanced`: より多くの推定候補を扱います。推定を含む場合は注記と Warning を出します。

CLI では `--visual-inference native-only|safe|balanced`、GUI では「接続推定なし」「安全優先」「復元優先」を選択できます。

## 3. 安全なフォールバック

曖昧、矛盾、または確度不足の接続は Mermaid として確定しません。利用可能な元テキスト、埋め込み画像、PDF のページプレビュー、プレースホルダー、診断を保持します。

`--no-diagrams` を指定した場合は Mermaid を出力せず、解決できた関係を読みやすい一覧として残します。

## 4. 形式別の改善

- DOCX: DrawingML／WPS／VML の図形とコネクタについて、離れた段落にある要素や複数段落ラベルをより適切に扱います。互換性のない座標基準は未解決として報告します。
- XLSX: 接続済みコネクタ、セル配置から判断できる関係、方向図形、フローチャート図形を保守的に扱います。未知の図形でもラベルは保持します。
- PPTX: 接続済み／未スナップのコネクタ、矢印、ラベル、非表示図形、複数の図に対応します。分離した矢印先端は、位置と向きが明確な場合だけ関連付けます。
- PDF: 単純なベクター形式のフローを条件付きで扱います。装飾的な三角形や V 字を接続として推測しません。

## 5. 互換性と既知の制約

対応中の一方向変換に移行作業は不要です。Markdown から Office への復元や新規文書生成は引き続き実験機能です。

任意の PDF ベクター図、SmartArt の完全な論理構造、Word の互換性がない座標基準、あらゆる分離矢印の復元は保証しません。詳しくは [対応機能](../docs/ja/supported-features.md) と [v0.1.7 正誤表](ERRATA_v0.1.7.md) を参照してください。

## 6. 利用時の注意

通常は `safe` を推奨します。Warning がある場合、CLI は終了コード 1 を返します。Markdown だけでなく、診断、生成された asset、元文書も確認してください。
