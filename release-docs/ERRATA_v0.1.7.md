# v0.1.7 正誤表

v0.1.7 Public Beta の DOCX visual semantics には、実ファイルで次の制約がありました。

- Word の一般的な `wp:anchor`／WPS／VML フローでは、図形と connector が別段落にある場合や、座標基準が混在する場合に接続を復元できないことがありました。
- connector が図形境界へ完全に snap されていない場合、端点が一意でも関係を出力しないことがありました。
- 反対に、長い connector が中間ノードを跨ぐ配置では、近傍だけを使った推定が遠方ノード間の偽関係を生成し得ました。
- edge label、複数図、flip／rotation、分離 arrowhead、文字のない図形は限定対応でした。

v0.2.0 では、対応形式に一貫した保守的な接続判定を適用し、`native-only`／`safe`／`balanced` を選択できます。未解決、曖昧、または確度不足のコネクタは関係として確定せず、元テキスト、画像等の代替表示、診断を保持します。v0.1.7 が生成した Mermaid を原図の完全な復元とみなさず、元文書と診断を確認してください。
