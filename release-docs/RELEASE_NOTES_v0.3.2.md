# DocRedock v0.3.2 Public Beta

[English](RELEASE_NOTES_v0.3.2.en.md)

v0.3.2は、Excelの表の区切りを改善し、変換後に確認する箇所と、読み順・表構造をどう得たかを分かりやすく表示します。AI向けパッケージには、大きなExcelの表を行単位で分割するオプションを追加します。

## Excelの表と見出し

- ID・行見出しと数量の間に空白列がある表で、対応する値を別の表に分けてしまう問題を修正しました。備考列も元の行との対応を保ちます。
- 独立した表や1列の候補リストは、それぞれの見出し・ラベルと配置をもとに分離します。数値だけの範囲でも、隣の表と行がずれていたり、年・月・日付などを独自のキーにしていたりする場合は、独立した表として扱います。Excelのテーブルとして定義された範囲も参照します。
- 空白列なしで接する表は、それぞれに結合タイトルがあり、表と凡例など構成が異なる場合に分離します。色や罫線の違いだけで一つの表を分割しません。
- 表のタイトルが隣の表の見出しに混ざる問題、表の前の短い説明が列見出しになる問題、通常の2列表に不要な「文書情報」の見出しが付く問題を修正しました。

配置から区切りを判断できない場合は、分離した範囲を原本との照合対象として案内します。この案内自体でCLIの終了コードは変わりません。複雑な表は引き続き原本と比較してください。

## 変換結果の確認案内

GUI・CLIの結果に、検出された要確認事項と、読み順・表構造が原本に基づくものか、配置から推定したものか、照合が必要か、未評価かを表示します。Excelの区切りが不確かな表は、対象シートとセル範囲を案内します。

「要確認事項が検出されなかった」ことは、変換内容の正しさを保証するものではありません。AIパッケージの`review.md`にも同じ確認案内を含めます。Markdownに出力した表の件数には、DocRedockが付けるOCR確認用の表を含めなくなりました。

## AI向けパッケージ

GUIの「大きなExcelの表を行ブロックに分割」、CLIの`--table-row-blocks`、APIの`TableRowBlocks: true`で、分割の目安を超えるExcelの表をデータ行の区切りで分割できます。各分割に見出し行を再掲し、元のセル範囲、表の識別子、分割の順番、前後の分割への参照を付けます。全文の`document.md`はそのまま保持します。

```sh
docredock export input.xlsx --ai-package zip --table-row-blocks
```

このオプションは既定では無効です。既定ではシートを一体で保持し、Word・PowerPoint・PDFの分割方法は従来どおりです。分割サイズは目安のため、長い1行などは目安を超えることがあります。

**連携ツール向けの互換性情報:** manifest schemaは`2.0`から`2.1`へ更新し、`table_row_blocks`、各分割の`estimated_tokens`、行ブロックの`table_block`を追加します。`estimated_tokens`はモデルに依存しない概算で、実際のトークン数や入力上限を保証しません。`report.json`はschema `1.1`となり、読み順・表構造の根拠と`review.table_boundaries`を追加します。`review.required`は表の区切りの照合も含めて判定します。読み取る側は対応するschemaを確認し、未知の追加項目を無視してください。

APIの`AiPackageManifestReader`とPythonの読み取り例で、manifest schema `1.x`・`2.x`の読み取りとファイルハッシュの確認ができます。未対応のメジャーバージョンは明示的なエラーにします。詳しくは[形式仕様](../docs/reference/ai-package.md)を参照してください。

## その他の修正

macOSで幅または高さが3ピクセル未満の小さな画像をOCRに渡さず、スペーサー画像による不要な失敗警告を抑えます。Vision OCRの処理が失敗した場合のメッセージも、短い1行で表示します。

## 利用上の制約と配布物

Public Betaのため、本番向けの安定版ではありません。PDF／Office変換や図の推定に関する既存の制約は継続します。OCRとPDF照合画像には、利用環境に応じてOCR providerやrasterizerの構成が必要です。

デスクトップGUIのPDF入力は既定で利用できます。CLIのPDF変換には引き続き`DOCREDOCK_ENABLE_EXPERIMENTAL=1`が必要です。往復編集、元形式への復元、PDF／Officeの新規生成も実験機能です。

AI向けパッケージはローカルで生成し、生成時に文書をアップロードしません。共有前に全文、画像、`review.md`を確認してください。

配布対象はWindows（x64／Arm64）、macOS（Intel／Apple Silicon）、Linux（x64／Arm64）です。公開時のGitHub ReleaseでOS／CPUに合う配布物と`SHA256SUMS`を確認してください。各パッケージの`SIGNING-STATUS.json`に署名・notarizationの適用状況を記録します。署名済みとは限りません。

詳しい手順は[利用ガイド](../docs/ja/user-guide.md)、対応範囲は[対応機能](../docs/ja/supported-features.md)を参照してください。
