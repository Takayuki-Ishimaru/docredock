# DocRedock v0.3.1 Public Beta

[English](RELEASE_NOTES_v0.3.1.en.md)

v0.3.1は、Excelの表の区切りとPDFの段組みの読み順を改善し、Wordの実験的な往復編集で不要な差分が発生する問題を修正します。AI向けパッケージの出典情報を整理し、分割した本文から章の位置を確認しやすくします。

## 文書変換の修正

- **Excel:** 1列の空白を挟んで隣り合う独立した表・候補リストが、一つの表に混ざる問題を修正しました。行見出しと数値の間に空白列を置いた表は、その対応を保持します。表全体にまたがる結合セルのタイトルは、列見出しにせず表の前に表示します。
- **PDF:** 行の長さが異なる二段組で、左右の段の本文が交互に混ざる問題を修正しました。段の間の空白を認識できる場合に、左段を読み終えてから右段を出力します。複雑なレイアウトは引き続き原本との照合が必要です。
- **Wordの往復編集（実験機能）:** 画像を含む未編集の段落に末尾の空白があると、変更したと誤判定して別の段落の編集・復元まで妨げる問題を修正しました。元の空白を保持し、実際に編集した箇所だけを変更として扱います。

## AI向けパッケージ

`manifest.json`の出典の重複を減らし、詳細なノード・セルの対応を`source-index.json`に分離しました。詳細索引もパッケージのハッシュ一覧に含まれます。全文と分割本文は従来どおり含まれます。

Wordの分割本文には、所属する章・節を示す`section_path`を付けます。表やリストだけの分割を取り出した場合も、親の見出しを確認できます。

**連携ツール向けの互換性情報:** manifestのschemaは、v0.3.0の`1.0`から`2.0`へ変更しました。manifestを直接読むツールは、共有の`locations`、各分割の`source_ids`と`node_count`、`source_index`が指す詳細索引に対応してください。詳細な`node_ids`とExcelの`cell_addresses`は索引に保存します。GUIでの書き出し、CLIの`--ai-package dir|zip`、全文Markdownの利用手順は従来どおりです。詳しくは[形式仕様](../docs/reference/ai-package.md)を参照してください。

CLI・GUIの変換結果とAIパッケージの`report.json`では、Markdownに実際に出力した表の件数を区別して案内します。Excelセルから組み立てた表も数えるため、表が出力されているのに件数がゼロに見える状況を改善しました。表の件数だけで内容や読み順の正しさを判断せず、本文も確認してください。

## 利用上の制約と配布物

Public Betaのため、本番向けの安定版ではありません。PDF／Office変換や図の推定に関する既存の制約は継続します。OCRとPDF照合画像には、利用環境に応じてOCR providerやrasterizerの構成が必要です。

デスクトップGUIのPDF入力は既定で利用できます。CLIのPDF変換には引き続き`DOCREDOCK_ENABLE_EXPERIMENTAL=1`が必要です。往復編集、元形式への復元、PDF／Officeの新規生成も実験機能です。

AI向けパッケージはローカルで生成し、生成時に文書をアップロードしません。共有前に全文、画像、`review.md`を確認してください。

配布対象はWindows（x64／Arm64）、macOS（Intel／Apple Silicon）、Linux（x64／Arm64）です。公開時のGitHub ReleaseでOS／CPUに合う配布物と`SHA256SUMS`を確認してください。各パッケージの`SIGNING-STATUS.json`に署名・notarizationの適用状況を記録します。署名済みとは限りません。

詳しい手順は[利用ガイド](../docs/ja/user-guide.md)、対応範囲は[対応機能](../docs/ja/supported-features.md)を参照してください。
