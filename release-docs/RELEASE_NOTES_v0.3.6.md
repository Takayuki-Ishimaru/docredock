# DocRedock v0.3.6 Public Beta

[English](RELEASE_NOTES_v0.3.6.en.md)

v0.3.6は、出力先にあるファイルの保護と、Word文書を同時に変換する際の安定性を改善する更新です。

## 既存のMarkdownと画像を保護

閲覧用Markdownの変換に失敗した場合やキャンセルした場合に、既存のMarkdownや同名の画像フォルダーを削除してしまうことがある問題を修正しました。同じ出力先への変換が重なった場合も、先に保存された出力を置き換えずに競合を通知します。

GUIで重複を避ける出力名を選ぶ際は、Markdownだけでなく同名の`.assets`ファイルやフォルダーも確認します。画像フォルダーが既にある場所へ出力してエラーになった場合も、その既存の内容を保持します。

CLIでは、`--force`を指定しない限り、変換開始後に作成された出力も置き換えません。`--force`は引き続き、指定した既存出力を置き換えるためのオプションです。

## 入力文書を含むフォルダーの置き換えを拒否

CLIで、入力文書を含むフォルダーを出力先として置き換えようとした場合の保護を強化しました。画像フォルダーの深い階層に入力文書がある場合や、シンボリックリンクの解決先に入力文書がある場合も対象です。`--force`を指定しても、入力文書を含むと判定したフォルダーは置き換えません。

出力先を変更して再実行してください。以前の版で変換に失敗した場合は、元文書と既存の出力が残っていることを確認してください。この更新で、既に失われたファイルを復元することはできません。

## 同時実行時の出力とWord設定を保持

AI向けパッケージの保存と、実験機能の往復編集用出力・復元・生成でも、保存直前に別の処理が作成した出力を置き換えないよう改善しました。同じ保存先を使う処理が競合した場合は、別の出力名を指定するか、完了後に再実行してください。

Wordの変換では、変更履歴の表示設定が別の変換に影響する問題を修正しました。異なる履歴設定で同時に変換しても、各変換に指定した設定を使用します。

## 互換性と利用上の制約

コマンドの指定方法、内容ポリシー、変更履歴の選択・既定値は維持します。AI向けパッケージのmanifestは引き続きschema `2.2`、`report.json`はschema `1.2`です。

Public Betaです。閲覧用MarkdownとAI向けパッケージは一方向の出力で、元文書を正本として保持してください。共有前に本文、画像、診断、`review.md`を確認してください。確認事項が検出されなかったことは、変換の正しさを保証しません。

デスクトップGUIのPDF入力は既定で利用できます。CLIのPDF変換には引き続き`DOCREDOCK_ENABLE_EXPERIMENTAL=1`が必要です。往復編集、元形式への復元、PDF／Officeの新規生成は実験機能です。OCR・PDF照合画像には、利用環境に応じたproviderやrasterizerの構成が必要です。図やSmartArt、複雑なレイアウトの完全再現は保証しません。

## 配布物と更新方法

GitHub Releaseで、OS／CPUに合うアーカイブを選んでください。

| OS | CPU | ファイル名 |
| --- | --- | --- |
| Windows | Intel／AMD 64-bit | `DocRedock-v0.3.6-win-x64.zip` |
| Windows | Arm64 | `DocRedock-v0.3.6-win-arm64.zip` |
| macOS | Intel | `DocRedock-v0.3.6-osx-x64.zip` |
| macOS | Apple Silicon | `DocRedock-v0.3.6-osx-arm64.zip` |
| Linux | Intel／AMD 64-bit | `DocRedock-v0.3.6-linux-x64.tar.gz` |
| Linux | Arm64 | `DocRedock-v0.3.6-linux-arm64.tar.gz` |

ダウンロード後は`SHA256SUMS`でチェックサムを照合し、展開したフォルダーの`QUICKSTART.ja.md`を参照してください。別途.NET SDKは不要です。署名・notarizationの適用状況は、各パッケージの`SIGNING-STATUS.json`を確認してください。署名済みとは限りません。既存の文書と出力を保管したうえで、アプリを終了して新しいパッケージへ置き換えてください。
