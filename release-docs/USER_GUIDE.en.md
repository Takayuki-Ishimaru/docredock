# DocRedock user guide

[日本語](USER_GUIDE.md) | English

The user guide has moved to [docs/en/user-guide.md](../docs/en/user-guide.md).

The current Public Beta supports one-way desktop-GUI DOCX/XLSX/PPTX/PDF to **Readable Markdown** or **AI package** conversion. Hidden content is excluded by default, but Word revision markup can include deleted text. Enable CLI PDF conversion with `--allow-pdf` or the experimental environment variable. Round-trip editing, restoration and generation remain experimental.
