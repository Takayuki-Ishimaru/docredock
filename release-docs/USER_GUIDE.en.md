# DocRedock user guide

[日本語](USER_GUIDE.md) | English

See how to get started, choose an export format, and review the result. [User guide](../docs/en/user-guide.md)

The Public Beta desktop app converts DOCX, XLSX, PPTX, and PDF to **Readable Markdown**, **Readable HTML**, or **AI packages**. It excludes recognized hidden content by default. Select **Final** in the Word revision settings to keep deleted text out of your export. Enable CLI PDF conversion with `--allow-pdf` or the experimental environment variable. Round-trip editing, restoration, and generation remain experimental.
