# Synthetic regression fixtures (v0.3.2 evaluation follow-up)

These inputs are generated by `tools/generate_v033_regression_fixtures.py` for the regression tests added after the v0.3.2 evaluation. Each workbook has a title, then a unit note and a condition note directly above a long sales table with a bold header (`売上実績（単位: 千円、税抜）`, `対象: 国内全店`, `商品 | 売上 | 数量`). The notes must stay text above the table rather than become its header or turn a two-column table into label/value pairs, and an AI package that cuts the table into row blocks repeats them before the header of every later block. All text is generic synthetic content.

Generator and generated content are covered by the repository MIT license (`LICENSE`). Office packages have no author properties, external relationships or templates.

Regenerate from the repository root using Python 3 (standard library only):

```sh
python3 tools/generate_v033_regression_fixtures.py --output tests/DocRedock.Tests/Fixtures/Evaluation/V032
python3 -m unittest discover -s tools -p test_generate_v033_regression_fixtures.py
```
