# Synthetic regression fixtures

These minimal inputs are generated independently by `tools/generate_v031_regression_fixtures.py` for the v0.3.1 regression tests. They reproduce table relationships, PDF column order, unedited Word image-paragraph equivalence, part context and package source metadata. The report-provided binaries are not redistributed. All text is generic synthetic content.

Generator and generated content are covered by the repository MIT license (`LICENSE`). Office packages have no author properties, external relationships, templates or embedded fonts. PDF inputs reference the built-in Helvetica font and embed no font bytes. DOCX images are plain solid-color rectangles generated by the script; no third-party media is included. Font names in Office XML are references only.

Regenerate from the repository root using Python 3 (standard library only):

```sh
python3 tools/generate_v031_regression_fixtures.py --output tests/DocRedock.Tests/Fixtures/Evaluation/V030
python3 -m unittest discover -s tools -p test_generate_v031_regression_fixtures.py
```

ZIP timestamps are fixed; repeated generation produces identical bytes. The regression tests consume these inputs directly from the source tree.
