# Synthetic PDF schedule and flow regression fixtures

These project regression inputs originate from the synthetic schedule/flow PDFs supplied on 2026-10-26. The original PDF bytes are retained: one was generated by ReportLab and the other was rewritten by pypdf to draw a non-overlapping diamond marker last. The original generator is not included; the committed fixtures make the regression checks reproducible without downloading another archive.

The documents contain fabricated task labels, vector shapes and references to the standard Helvetica fonts. They contain no real user documents, embedded font programs, images, attachments or scripts. These source-test fixtures follow the repository's [MIT License](../../../../../LICENSE) and are excluded from end-user distribution archives.
